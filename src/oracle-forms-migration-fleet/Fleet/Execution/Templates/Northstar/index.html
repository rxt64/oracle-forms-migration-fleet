About Northstar Online Banking

The original Oracle Forms .fmb source is not running here. No Oracle Forms runtime, Forms Services component, or compiled module is loaded by this page.

This is a browser replica that implements the published workflow requirements of the public Oracle Apps case study against the synthetic demo Oracle database exposed by this application's HTTP API.

All accounts, staff users, balances and transactions are invented seed data. Nothing in this environment corresponds to a real person, account, or transaction.
